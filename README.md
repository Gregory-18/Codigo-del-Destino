# Código del Destino: El Misterio Interactivo

Un juego de aventura web interactivo donde los jugadores deben descifrar pistas y resolver acertijos para avanzar en una historia misteriosa.

## Descripción

"Código del Destino" es una experiencia interactiva donde los usuarios se sumergen en una narrativa enigmática. Cada capítulo presenta un nuevo acertijo que el jugador debe resolver para avanzar. El juego combina elementos visuales atractivos, narrativa inmersiva y desafíos lógicos para crear una experiencia envolvente.

## Características

- **Historia Progresiva**: La narrativa se revela a medida que el jugador resuelve los acertijos.
- **Acertijos Variados**: Incluye diferentes tipos de puzzles (numéricos, textuales, lógicos).
- **Interfaz Inmersiva**: Diseño visual que refuerza la atmósfera de misterio.
- **Sistema de Pistas**: Los jugadores pueden solicitar ayuda si se quedan atascados.
- **Seguimiento de Estadísticas**: El juego registra el tiempo y pistas utilizadas.

## Tecnologías Utilizadas

- HTML5
- CSS3 (con animaciones y transiciones)
- JavaScript (Vanilla JS)

## Cómo Jugar

1. Abre el archivo `index.html` en tu navegador web.
2. Haz clic en "Comenzar Aventura" para iniciar la experiencia.
3. Lee atentamente la historia y las pistas proporcionadas.
4. Resuelve cada acertijo para avanzar al siguiente capítulo.
5. Si necesitas ayuda, puedes solicitar pistas adicionales.

## Personalización y Expansión

El juego ha sido diseñado para ser fácilmente expandible. Puedes añadir nuevos capítulos y acertijos modificando el array `chapters` en el archivo `script.js`.

### Cómo añadir un nuevo capítulo:

1. Añade un nuevo objeto al array `chapters` siguiendo la estructura existente.
2. Define el contenido, tipo de puzzle y respuestas correctas.
3. Asegúrate de que el `id` del nuevo capítulo sea secuencial.
